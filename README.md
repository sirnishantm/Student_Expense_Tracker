# Student Expense Tracker – Project Description

The Student Expense Tracker is a front-end web application built using HTML, CSS, and JavaScript that allows students to record, manage, and monitor their daily expenses in a simple and intuitive interface.

Purpose

Managing finances is a crucial skill for students. This application provides a lightweight, browser-based tool where students can log every expense, categorize it, and instantly see how much they have spent — helping them stay within budget and develop responsible spending habits.

Features

The application includes the following key features:

Add Expenses: Users can enter an expense name, amount, and select a category (Food, Travel, Shopping, Education, or Other) through a clean input form. Clicking the "Add Expense" button dynamically adds the entry to the list without reloading the page.

Dynamic Expense Display: Each expense is displayed as a card showing the name, amount, and a color-coded category badge for quick visual identification.

Total Calculation: A running total of all expenses is calculated and displayed in real time, updating automatically whenever an expense is added or removed.

Delete Functionality: Every expense card includes a "Delete" button that removes the entry and immediately recalculates the total.

Input Validation: The form validates all fields before submission — empty names, missing categories, and invalid or non-positive amounts are rejected with clear inline error messages.

Category Filter: A dropdown filter allows users to view expenses belonging to a specific category, making it easy to analyze spending patterns.

Technology Used

The project is built entirely with core web technologies:

HTML for semantic page structure and form elements.
CSS for a responsive, visually appealing design with gradient backgrounds, hover effects, animations, and mobile-friendly layout.
JavaScript and DOM Manipulation for all dynamic functionality including adding/deleting expenses, real-time total updates, validation, and filtering — all without any page reloads or external libraries.
Conclusion

This project demonstrates practical use of front-end development fundamentals — form handling, event-driven programming, DOM manipulation, and responsive design — packaged into a useful, real-world application.
